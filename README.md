# BoltSonnet

BoltSonnet is a high-performance, containerized orchestrator that manages real-time event-driven workflows with auto-scaling capabilities as a controller.

BoltSonnet is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/BoltSonnet.git`
2. `cd BoltSonnet`
3. Install in editable mode: `pip install -e .`

## Configuration

BoltSonnet is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
